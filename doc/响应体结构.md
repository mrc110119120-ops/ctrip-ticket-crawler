# 携程航班批量查询响应体结构

本文整理自 `browser_automation/results.json` 对应的成功响应样本，核心接口为 `batchSearch` 返回的 JSON。

## 1. 顶层结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `status` | number | 状态码，`0` 表示成功 |
| `msg` | string | 返回消息，成功时通常为 `"success"` |
| `data` | object | 核心数据容器 |

## 2. `data` 对象

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `context` | object | 查询上下文信息，通常包含 `searchId`、`finished`、`flag` 等字段 |
| `flightItineraryList` | array | 航班行程列表，每个元素表示一个可售方案 |
| `giftIds` | string | 赠品 ID，可能为空 |
| `bestChoiceFlightsForceTop` | boolean | 是否强制把优选航班置顶 |
| `recommendProduct` | object | 推荐产品信息，例如邻近航线推荐 |
| `needUserLogin` | boolean | 是否需要登录 |
| `lgn` | boolean | 登录状态标记 |

## 3. `flightItineraryList[]`

`flightItineraryList` 的每个元素代表一个行程方案。一个行程可能是直飞，也可能包含中转。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `itineraryId` | string | 行程唯一标识，例如 `EU7347_1788218100000` |
| `flightSegments` | array | 航段列表 |
| `priceList` | array | 票价 / 舱位组合列表 |
| `itineraryTags` | array | 行程标签，例如联程、通程、权益提示 |

### 3.1 `flightSegments[]`

每个元素表示一段连续航班。直飞通常只有 1 段，中转则会有多段。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `segmentNo` | number | 航段序号 |
| `airlineCode` | string | 市场承运人二字码 |
| `airlineName` | string | 市场承运人名称 |
| `crossDays` | number | 跨天数，`0` 表示当日到达 |
| `transferCount` | number | 中转次数，`0` 表示直飞 |
| `stopCount` | number | 经停次数 |
| `duration` | number | 航段总时长，单位分钟 |
| `flightList` | array | 具体航班列表 |
| `segmentType` | string | 一般为 `"FLIGHT"` |
| `transferRemark` | object | 中转说明，可选 |

### 3.2 `flightList[]`

`flightList` 描述具体航班本身。中转行程里通常有多个航班对象。

| 字段 | 说明 |
| --- | --- |
| `flightNo` | 航班号 |
| `marketAirlineCode` / `marketAirlineName` | 市场承运人二字码 / 名称 |
| `operateAirlineCode` / `operateAirlineName` | 实际承运人二字码 / 名称 |
| `operateFlightNo` | 实际承运航班号，共享航班时可能与 `flightNo` 不同 |
| `departureCityCode` / `departureCityName` | 出发城市 |
| `departureAirportCode` / `departureAirportName` | 出发机场 |
| `departureTerminal` | 出发航站楼 |
| `departureDateTime` | 出发时间 |
| `arrivalCityCode` / `arrivalCityName` | 到达城市 |
| `arrivalAirportCode` / `arrivalAirportName` | 到达机场 |
| `arrivalTerminal` | 到达航站楼 |
| `arrivalDateTime` | 到达时间 |
| `duration` | 该航段时长 |
| `aircraftCode` / `aircraftName` / `aircraftSize` | 机型信息 |
| `mealType` | 餐食类型 |
| `arrivalPunctuality` | 到达准点率 |
| `stopList` | 经停点列表，通常为空 |

### 3.3 `priceList[]`

`priceList` 描述同一行程下不同舱位或产品组合的价格选项。项目里的解析逻辑会优先选择成人价最低的方案，再按儿童价和婴儿价做补充比较。

| 字段 | 说明 |
| --- | --- |
| `adultPrice` / `childPrice` / `infantPrice` | 成人 / 儿童 / 婴儿价格 |
| `freeOilFeeAndTax` | 是否免燃油费和税费 |
| `ticketCount` | 剩余票数 |
| `cabin` | 舱位等级，例如 `Y`、`C` |
| `invoiceType` | 发票类型 |
| `priceUnitList` | 价格单元列表，包含舱位细节 |
| `baggage` | 行李额信息 |
| `penalty` | 退改签规则 |
| `restrictionList` | 限制条件 |
| `priceTags` | 附加标签，例如“免机建燃油费”“3折”等 |
| `servicePackage` | 服务包 |
| `groupType` | 产品分组 |
| `defaultCollapse` | 是否默认折叠 |
| `sortPrice` | 排序价格 |
| `key` / `matchedKey` | 用于识别的键值 |
| `tagAttrList` | 标签属性 |

#### `priceUnitList[].flightSeatList[]`

| 字段 | 说明 |
| --- | --- |
| `segmentNo` | 对应航段号 |
| `sequenceNo` | 序号 |
| `seatClass` | 舱位代码，例如 `K`、`V`，可能带数字后缀 |
| `discountRate` | 折扣率，`0.37` 表示 3.7 折 |
| `accumulateMileage` | 累积里程，`-1` 表示无 |
| `productTypes` | 产品类型数组 |

#### `baggage`

| 字段 | 说明 |
| --- | --- |
| `baggageTag` | 简短行李说明，例如“托运行李额20KG” |
| `iconType` | 图标类型 |
| `dataList` | 详细行李规则，通常区分成人、儿童与手提行李 |

#### `penalty`

| 字段 | 说明 |
| --- | --- |
| `defaultPenaltyTag` | 简短退改签标签 |
| `penaltyCriteria` | 退改签规则的详细 JSON 字符串 |
| `defaultPenalty` | 展示用的退改签说明 |

### 3.4 `itineraryTags[]`

用于标记行程的特殊属性，例如联程、通程、权益说明等。

| 字段 | 说明 |
| --- | --- |
| `type` | 标签类型，例如 `G5_LC_Flight`、`ApprovedVirtualFlight` |
| `label` | 页面展示的标签文本 |
| `data` | 标签携带的数据，可能包含 `bookingNotice`、`tags`、`segments` |

## 4. 其他顶层字段

| 字段 | 说明 |
| --- | --- |
| `recommendProduct.recommendInfoList` | 邻近航线推荐信息 |
| `giftIds` | 可能为空字符串 |

## 5. 结构总结

整个响应体是一个层级清晰的航班搜索模型：

1. 顶层提供状态和容器。
2. `flightItineraryList` 提供行程级结果。
3. 每个行程下再分为航段、具体航班和价格选项。
4. 价格选项中附带行李、退改签、标签、折扣等细节。

如果后续需要补充字段，建议继续以实际响应样本为准追加，不要先验假设字段一定存在。
